# Список задач на Flask

Учебный проект для занятия «Python и Web». Добавьте задачу через HTML-форму или JSON API, отметьте её выполненной и проверьте, что она сохранилась после перезапуска приложения. Оба интерфейса работают с одной базой SQLite.

## Как запустить

Установите Python 3.10 или новее. Скачайте или клонируйте репозиторий и откройте терминал в папке с файлом `app.py`.

**macOS и Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m flask --app app init-db
python app.py
```

**Windows (PowerShell)**

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app init-db
.\.venv\Scripts\python.exe app.py
```

Откройте [список задач](http://127.0.0.1:5000/tasks). Чтобы остановить сервер, нажмите `Ctrl+C` в терминале. При следующем запуске на macOS и Linux сначала активируйте окружение. Затем выполните последнюю команду для своей системы.

Команда `init-db` создаёт таблицу в `instance/tasks.sqlite3`. Эту команду можно повторить, и существующие задачи сохранятся.

## Первые запросы

1. Добавьте задачу на странице и откройте [список в JSON](http://127.0.0.1:5000/api/tasks). Найдите поля `id`, `title` и `done`.
2. Отметьте задачу выполненной. Откройте [фильтр выполненных задач](http://127.0.0.1:5000/api/tasks?done=1) и проверьте, что задача попала в ответ.
3. Вернитесь на страницу задач. Нажмите правой кнопкой по странице и выберите «Просмотреть код» или «Исследовать». На вкладке **Network** («Сеть») включите **Preserve log** и добавьте ещё одну задачу. В **Payload** запроса `POST /tasks` найдите поле `title`. В **Headers** проверьте статус `303` и заголовок `Location: /tasks`. Следующий запрос `GET /tasks` загрузит обновлённый список.

## JSON API

| Запрос | Что делает | Успешный ответ |
| --- | --- | --- |
| `GET /api/tasks` | Возвращает все задачи. Параметр `done=0` оставляет невыполненные, `done=1` — выполненные. | `200 OK`, объект с массивом `tasks` |
| `POST /api/tasks` | Создаёт задачу из JSON `{"title": "Разобраться с HTTP"}`. | `201 Created`, объект новой задачи |

Для POST укажите `Content-Type: application/json`. Название должно содержать от 1 до 120 символов после удаления пробелов по краям. При неверном фильтре, теле запроса или названии сервер вернёт `400 Bad Request`. Если заголовок `Content-Type` отсутствует или указывает тип данных, отличный от JSON, сервер вернёт `415 Unsupported Media Type`.

В другом терминале запустите [клиент на HTTPX](client.py). На macOS и Linux активируйте окружение командой `source .venv/bin/activate`. В PowerShell используйте `.\.venv\Scripts\python.exe` вместо `python`.

```bash
python client.py
python client.py --add "Проверить JSON API"
python client.py --done 0
```

В [requests.http](requests.http) есть готовые запросы для HTTP-клиента IDE, в том числе запросы с ошибками. Попробуйте отправить пустое название и сравнить ответ с ответом на корректный запрос.

## Как запустить тесты

Из папки проекта выполните команды в том же виртуальном окружении:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

В PowerShell используйте `.\.venv\Scripts\python.exe` вместо `python`. Фикстура `app` создаёт отдельную SQLite-базу для каждого теста, а `client` отправляет запросы приложению без запуска сервера. Декоратор `@pytest.mark.parametrize` прогоняет одну проверку с разными входными данными.

## Самостоятельная работа

- Добавьте на страницу задач фильтр «Все / В работе / Выполнены». Посмотрите, как обработчик `GET /api/tasks` получает `done` через `request.args` и передаёт его в `read_tasks()`.
- Добавьте `GET /api/tasks/<int:task_id>`. Если задача найдена, верните `200 OK` и объект с полями `id`, `title` и `done`. Если задачи с таким идентификатором нет, верните `404 Not Found`.
- Добавьте `DELETE /api/tasks/<int:task_id>`. Удалите задачу из SQLite и верните `204 No Content` с пустым телом. Если задачи уже нет, верните `404 Not Found`.

Передавайте `task_id` в SQL как параметр. В pytest проверьте, что GET возвращает нужную задачу, а после DELETE тот же GET возвращает `404`. Повторный DELETE тоже должен вернуть `404`.

## Домашнее задание. Гостевая книга

Сделайте своё приложение на Flask по образцу списка задач.

- Покажите на странице отзывы с именем автора и текстом.
- Добавьте форму и проверяйте оба поля на сервере. Строки из одних пробелов считаются пустыми.
- Сохраняйте отзывы в SQLite. Проверьте, что они доступны после перезапуска.
- После успешного POST перенаправляйте браузер на страницу отзывов. Обновление страницы не должно добавлять отзыв повторно.
- Включите в проект README с командами запуска.

Дополнительное задание — фильтрация отзывов по имени автора.

## Если запуск не получился

- При ошибке `no such table: task` выполните команду `init-db` из инструкции по запуску.
- Если порт 5000 занят, запустите `python -m flask --app app run --port 5001`. В браузере используйте порт 5001, а клиенту передайте `--url http://127.0.0.1:5001`.
